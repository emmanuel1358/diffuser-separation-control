# Repair the repository slug normalizer

Repair the Python repository at:

```text
/tmp/output/repo
```

Edit that repository directly. The final repository at the same path is the
submitted artifact.

The public API is `normalizer.normalize_slug(value)`. Preserve that function
name and implement this contract for ASCII text:

1. Remove leading and trailing whitespace.
2. Convert letters to lowercase.
3. Replace each run of non-alphanumeric characters with one hyphen.
4. Remove leading and trailing hyphens.
5. Return `untitled` when the input contains no alphanumeric characters.

Examples:

- `Release Candidate` becomes `release-candidate`.
- ` API / V2 ` becomes `api-v2`.
- `---` becomes `untitled`.

Keep the repository source-only and use the Python standard library. Do not add
generated bytecode, native binaries, archives, or symlinks. You may add or
improve tests. Run the public suite from the repository with:

```bash
python3 -m unittest discover -s tests -v
```

Hidden checks exercise additional punctuation, repeated separators, boundary
whitespace, empty values, and deterministic repeated execution.
